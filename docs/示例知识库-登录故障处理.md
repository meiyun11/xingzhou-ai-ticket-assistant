# 星舟协作平台：登录故障处理规范

本文为个人项目编写的虚构演示资料，不代表任何公司的内部规范。

## 认证规则

access_token 有效期为 30 分钟。客户端发送请求时，使用 `Authorization: Bearer <access_token>`。开发、测试、生产环境令牌不能混用。

## 登录接口出现 401

依次检查令牌是否过期、Authorization 是否使用正确的 Bearer 格式、令牌签发环境是否与请求环境相同。确认账号是否被停用。客户端日志只记录脱敏后的错误码与请求 ID，不记录完整令牌。

## 工单必填信息

提交登录故障工单时，必须包含问题标题、发生环境、发生时间、错误码和复现步骤。环境只能填写开发、测试或生产。请求 ID 可选。不允许在工单中粘贴密码、完整 access_token 或私钥。

## 重复问题

创建工单前，查询是否有同环境、同错误码的未关闭工单。如果发现相同问题，先展示已有工单，由用户确认是否仍需新增。

## 知识范围

本资料没有提供 JWT 私钥、真实用户账号、生产服务器地址、退款政策或其他业务规则。遇到资料未覆盖的问题，应说明缺少依据，不编造配置或政策。
